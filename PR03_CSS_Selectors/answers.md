# Ответы на вопросы ПР №3

1. Класс .class повторно используемый, специфичность 0,1,0. ID #id уникален, специфичность 1,0,0.
2. Каскад: при конфликте учитываются важность (!important), специфичность, порядок объявления.
3. Специфичность: ul li.important — 0,1,2; #site-title — 1,0,0; .content > .featured-post — 0,2,0.
4. Наследуются: color, font-family, line-height. Не наследуются: margin, padding, border.
5. > — дочерний селектор (прямой потомок); пробел — все потомки любой глубины.
6. :hover — при наведении; :nth-child() — выбор по порядку. Пример: подсветка строк таблицы.
7. !important переопределяет все правила, ломает каскад, используется только в крайнем случае.
8. ::before/::after добавляют контент до/после элемента через content.
9. При равной специфичности — побеждает правило, объявленное позже.
10. DevTools показывают, какие стили применены, откуда и с какой специфичностью.
