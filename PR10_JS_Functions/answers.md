# Ответы на вопросы ПР №10

1. Function Declaration поднимается (hoisting), Function Expression — нет.
2. Rest parameters собирают аргументы в массив; arguments — старый объект.
3. Замыкание — функция + её лексическое окружение.
4. Рекурсия — элегантна для деревьев; итерация — быстрее и без переполнения стека.
5. Функции высшего порядка принимают/возвращают функции: map, filter, reduce.
6. Каррирование превращает f(a,b,c) в f(a)(b)(c).
7. Мемоизация кэширует результаты — эффективна для тяжёлых вычислений.
8. debounce — ждёт паузу; throttle — ограничивает частоту.
9. Генераторы (function*) возвращают итератор с yield.
10. Чистые функции, иммутабельность, композиция.
