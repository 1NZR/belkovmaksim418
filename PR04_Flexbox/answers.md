# Ответы на вопросы ПР №4

1. display: flex включает Flexbox. Дочерние элементы становятся flex-элементами и выстраиваются вдоль главной оси.
2. justify-content — выравнивание по главной оси, lign-items — по поперечной.
3. lex-direction — задаёт направление главной оси: row, row-reverse, column, column-reverse.
4. lex: 1 = flex-grow:1; flex-shrink:1; flex-basis:0%.
5. lex-wrap позволяет элементам переноситься на новую строку.
6. lign-content — выравнивание строк внутри контейнера (при wrap), lign-items — элементов внутри строки.
7. order меняет порядок отображения. Пример: вывод важных карточек первыми.
8. Main axis — ось вдоль flex-direction; cross axis — перпендикулярная ей.
9. Без медиа-запросов адаптивность достигается через lex-wrap: wrap и lex-basis/min-width.
10. gap не создаёт внешних отступов и не ломает раскладку, в отличие от margin.
