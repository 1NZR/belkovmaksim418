# Ответы на вопросы ПР №5

1. display: grid. Grid — двумерный, Flexbox — одномерный.
2. grid-template-columns — явные колонки, grid-auto-columns — для неявно создаваемых колонок.
3. epeat(n, 1fr) — повтор; minmax(200px, 1fr) — мин/макс размер; uto-fit — автоматически вписывает колонки.
4. Именованные области (grid-template-areas) — наглядное описание макета.
5. Линии нумеруются с 1. grid-column: 1 / 3 — от 1-й до 3-й линии.
6. gap не создаёт внешних отступов, чище и удобнее.
7. justify-items — по главной оси, lign-items — по поперечной.
8. uto-fill создаёт пустые колонки, uto-fit их сворачивает.
9. Имена областей — идентификаторы, повторяющиеся для объединения ячеек.
10. Grid — самый мощный инструмент для двумерных макетов, поддерживает именование, адаптивность и точный контроль.
