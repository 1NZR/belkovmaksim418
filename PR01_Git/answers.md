# Ответы на вопросы ПР №1

1. **Три области Git:** рабочая папка (файлы на диске), индекс (staging area — подготовленные к коммиту изменения), репозиторий (.git — зафиксированная история).
2. git add — добавляет изменения в индекс; git commit — фиксирует их в локальной истории; git push — отправляет коммиты на удалённый сервер.
3. Информативные сообщения позволяют понять, что и зачем было изменено, облегчают ревью и откат.
4. git add имя_файла добавляет один файл, git add . — все изменения. Первое — точечно, второе — когда нужно закоммитить всё сразу.
5. git status показывает текущее состояние рабочей папки и индекса.
6. git remote add origin URL привязывает локальный репозиторий к удалённому; origin — стандартное имя удалённого репозитория.
7. -u устанавливает upstream-ветку, чтобы потом писать просто git push.
8. Ветка по умолчанию — main (или master в старых версиях).
9. git log — история коммитов: hash, автор, дата, сообщение.
10. Изменения останутся в рабочей папке, но не попадут в коммит, пока не выполнить git add.
