# Ответы на вопросы ПР №9

1. O(n) — линейная (findMax), O(n²) — квадратичная (bubbleSort).
2. Бинарный поиск делит массив пополам — O(log n), т.к. на каждом шаге отбрасывается половина.
3. Пузырьковая: простая, но O(n²); минус — медленная на больших данных.
4. Оптимизация: проверка до √n, пропуск чётных.
5. Рекурсивная — элегантна, но O(2ⁿ); итеративная — O(n).
6. console.log, breakpoints, DevTools.
7. Алгоритм Евклида: НОД(a,b) = НОД(b, a mod b).
8. Пустой массив, один элемент, дубликаты, отрицательные числа.
9. Set/Map — O(n), объект-счётчик.
10. Читаемые имена, комментарии, декомпозиция.
