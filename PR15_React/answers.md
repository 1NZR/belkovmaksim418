# Ответы на вопросы ПР №15

1. Функциональные проще, используют хуки; классовые нужны для legacy.
2. props — входные, read-only; state — внутреннее, изменяемое.
3. Lifting state up — поднятие состояния к общему родителю.
4. componentDidMount, componentDidUpdate, componentWillUnmount.
5. useState — состояние, useEffect — побочные эффекты. Правила хуков: только на верхнем уровне.
6. keys помогают React идентифицировать элементы при рендере списков.
7. В React обработчики передаются как props, синтетические события.
8. Controlled — значение через state, uncontrolled — через ref.
9. Context передаёт данные без prop drilling.
10. Кастомные хуки инкапсулируют логику, легко тестируются и переиспользуются.
